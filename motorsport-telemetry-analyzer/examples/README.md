# Example Data

These files are intentionally small, public-safe extracts from validated real FH6 analysis outputs.

- `data/reference-lap-03-normalized.csv` contains the 400-point reference lap with selected telemetry channels.
- `data/lap-02-vs-lap-03-comparison.csv` contains distance-aligned comparison channels and cumulative time-delta behavior.
- `data/semantic-segment-boundaries.csv` contains the V1.1 13-segment partition (6 telemetry-derived corners, 7 straights).
- `data/validation-anchors.csv` contains the protected headline numerical anchors used in the public documentation.

Raw UDP/native capture files are intentionally not published in this showcase.
